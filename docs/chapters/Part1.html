Les valeurs manquantes ne sont pas dispersées au hasard : elles concernent 80 stations, chacune ayant exactement 24 observations sans capacité. Il s’agit donc d’un problème lié à certaines stations (ou à une période précise), et non d’erreurs ponctuelles de mesure.

2.2.4 Traitement retenu

Le traitement des valeurs manquantes de capacity est réalisé dans la section ?@sec-nettoyage (Nettoyage et agrégation des données) : les lignes sans capacité sont exclues avant le calcul du taux d’occupation (bikes_available / capacity), car ce taux n’est pas défini sans capacité. Les 80 stations concernées ne figurent donc pas dans la table agrégée stations. Elles représentent une faible part des données (environ 0,6 % des lignes).

3 Visualisation

3.1 Carte des stations Vélib’

La carte ci-dessous montre l’emplacement des stations. La couleur indique le nombre moyen de vélos disponibles : les stations jaunes sont souvent bien remplies, les violettes souvent presque vides.

import plotly.express as px
# Suppression des stations sans coordonnées
df_map = (
    raw.dropna(subset=["latitude", "longitude"])
       .groupby("station_code", as_index=False)
       .agg(
           name=("name", "first"),
           commune=("commune", "first"),capacity=("capacity", "first"),
           latitude=("latitude", "first"),longitude=("longitude", "first"),
           bikes_available=("bikes_available", "mean"), ) )
print("Nombre de stations :", len(df_map))

fig = px.scatter_map(
    df_map,lat="latitude",lon="longitude",hover_name="name",
    hover_data=["station_code", "commune", "capacity"],

    title="Répartition des stations Vélib' à Paris (nombre moyen de vélos)")

fig.update_layout(
    map=dict(center=dict(lat=48.8566, lon=2.3522), zoom=10.5),

fig.show()

3.4 Nettoyage et agrégation des données

import numpy as np
import pandas as pd
import plotly.express as px

JOURS = ["Lundi", "Mardi", "Mercredi", "Jeudi", "Vendredi", "Samedi", "Dimanche"]
VERT = ["#DCFCE7", "#86EFAC", "#22C55E", "#15803D", "#14532D"]

TIME_COL = "collected_at_utc"

df = raw.copy()
df["ts"] = pd.to_datetime(df[TIME_COL], errors="coerce", utc=True).dt.tz_convert("Europe/Paris")
df = df.dropna(subset=["ts", "latitude", "longitude"])
df = df[(df["capacity"] > 0) & (df["is_installed"] == 1)].copy()

df["hour"] = df["ts"].dt.hour
df["weekday"] = df["ts"].dt.dayofweek
df["periode"] = np.where(df["weekday"] >= 5, "Week-end", "Semaine")
df["occupancy"] = df["bikes_available"] / df["capacity"]

stations = (
    df.groupby("station_code", as_index=False)
      .agg(name=("name", "first"), commune=("commune", "first"),
           capacity=("capacity", "first"),
           latitude=("latitude", "first"), longitude=("longitude", "first"),
           bikes_available=("bikes_available", "mean"),
           occupancy=("occupancy", "mean"))
)

print("Nombre de stations :", len(stations))
print("Période :", df["ts"].min(), "->", df["ts"].max())
print("Nombre de jours :", df["ts"].dt.date.nunique())

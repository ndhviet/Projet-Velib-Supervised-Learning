1.2 Vérification des données

URL = "https://docs.ambroise.cloud/velib/velib-2026-10-08.csv.gz"
FILE = "data/velib-2026-10-08.csv.gz"
MD5 = "02ab1e3fdac10579e4ce93d1540a5dc7"

path, _ = urllib.request.urlretrieve(URL, FILE)
print("Download successful:", path)
print("---------------------------------------------------")
with open(path, "rb") as f:
    calculated_md5 = hashlib.md5(f.read()).hexdigest()

print("Calculated MD5:", calculated_md5)
print("Expected MD5:  ", MD5)

assert calculated_md5 == MD5, f"MD5 mismatch: {calculated_md5}"
print("MD5 OK!")

Les valeurs manquantes ne sont pas dispersées au hasard : elles concernent 80 stations, chacune ayant exactement 24 observations sans capacité. Il s’agit donc d’un problème lié à certaines stations (ou à une période précise), et non d’erreurs ponctuelles de mesure.

La variable capacity n’intervient pas dans la définition de la cible (qui repose sur mechanical_bikes + electric_bikes). Elle est laissée telle quelle et n’est pas utilisée comme variable explicative.

2.2.4 Cohérence interne et statut des stations

N_tmp   = raw["mechanical_bikes"] + raw["electric_bikes"]
cap_sum = raw["bikes_available"] + raw["docks_available"]

print("\n--- Cohérence ---")
print("bikes_available != mécaniques + électriques :", (raw["bikes_available"] != N_tmp).sum())
print("vélos + bornettes > capacité                :", (cap_sum > raw["capacity"]).sum())   # impossible, à examiner
print("vélos + bornettes < capacité                :", (cap_sum < raw["capacity"]).sum())   # peut-être des bornettes hors service
print("vélos > capacité                            :", (N_tmp > raw["capacity"]).sum())
print("capacité == 0                               :", (raw["capacity"] == 0).sum())
# Remarque : une comparaison avec NaN renvoie toujours False ; les NaN sont donc comptés séparément ci-dessous

1 Construction du modèle supervisé

Pour chaque station \(s\) et chaque instant \(t\) (pas de 15 minutes), on définit le nombre total de vélos disponibles par

\[ N_{s,t} = M_{s,t} + E_{s,t} \]

où \(M_{s,t}\) et \(E_{s,t}\) désignent respectivement les nombres de vélos mécaniques et électriques.

La variable à prédire, pour un horizon \(h \in \{30, 60\}\) minutes, est définie par :

\[ Y_{s,t} = \mathbf{1}\{N_{s,t+h} < 2\} \]

Elle vaut 1 si la station compte moins de deux vélos \(h\) minutes plus tard, et 0 sinon. Elle suit une loi de Bernoulli de paramètre \(p_{s,t}\) :

\[ Y_{s,t} \sim \mathrm{Bernoulli}(p_{s,t}), \qquad p_{s,t} = \mathbb{P}(Y_{s,t}=1). \]

On note \(X_{s,t}\) l’ensemble des informations disponibles à l’instant \(t\). L’objectif est d’estimer :

\[ p(x) = \mathbb{P}(Y_{s,t}=1 \mid X_{s,t}=x). \]

Les lignes pour lesquelles la station n’est pas observée ou est fermée à \(t\) ou à \(t+h\) sont exclues. Aucune valeur manquante n’est interpolée : les rares retards qui tombent dans une panne ou une fermeture restent NaN, et les modèles les remplacent par la médiane du train (calculée sur le train seul).

3 Bayes naïf gaussien

Le modèle repose sur la formule de Bayes :

\[ p(x) = \frac{\pi f_1(x)}{\pi f_1(x) + (1-\pi) f_0(x)}, \qquad \pi = \mathbb{P}(Y=1), \]

où \(f_y\) est la densité de \(X\) sachant \(Y=y\), avec deux hypothèses :

  1. Gaussienne : \(X_j \mid Y=y \sim \mathcal N(\mu_{j,y}, \sigma^2_{j,y})\).
  2. Indépendance conditionnelle (le côté « naïf ») : \(f_y(x) = \prod_j f_{j,y}(x_j)\).

Les paramètres \(\pi\), \(\mu_{j,y}\), \(\sigma^2_{j,y}\) sont estimés sur le jeu d’apprentissage uniquement. La variable dow (0 à 6) n’est pas utilisée : un modèle gaussien la lirait comme une grandeur ordonnée (dimanche « loin » de lundi) ; on garde weekend et l’heure.

3.1 La classe

print(inspect.getsource(BayesNaifGaussien))
class BayesNaifGaussien:
    """Classifieur de Bayes naïf gaussien, écrit à la main."""

    def fit(self, X, y, eps=1e-9):
        X, y = np.asarray(X, dtype=float), np.asarray(y)
        self.classes_ = np.unique(y)
        # pi_ : proportion de chaque classe (partie Bernoulli de Y)
        self.pi_ = np.array([np.mean(y == k) for k in self.classes_])
        # Hypothèse 1 : une moyenne et un écart-type par variable et par classe
        self.mu_ = np.array([X[y == k].mean(axis=0) for k in self.classes_])
        self.sigma_ = np.array([X[y == k].std(axis=0) for k in self.classes_]) + eps
        return self

    def _log_densite(self, X, k):
        mu, sigma = self.mu_[k], self.sigma_[k]
        # log-densité gaussienne de chaque variable (hypothèse 1)
        log_f_1d = (-0.5 * np.log(2 * np.pi) - np.log(sigma)
                    - (X - mu) ** 2 / (2 * sigma ** 2))        # (n, nb_variables)
        # Hypothèse 2 : indépendance conditionnelle -> somme des log-densités
        return np.sum(log_f_1d, axis=1)                         # (n,)

    def _log_posterieurs(self, X):
        return np.array([np.log(self.pi_[k]) + self._log_densite(X, k)
                         for k in range(len(self.classes_))])    # (2, n)

    def predict_proba(self, X):
        lp = self._log_posterieurs(np.asarray(X, dtype=float))
        lp = lp - lp.max(axis=0)          # stabilité numérique
        p = np.exp(lp)
        return (p / p.sum(axis=0)).T      # colonne 1 = P(Y = 1 | x)

    def predict(self, X, tau=None):
        if tau is None:
            return self.classes_[np.argmax(self._log_posterieurs(np.asarray(X, dtype=float)), axis=0)]
        return (self.predict_proba(X)[:, 1] > tau).astype(int)

4 Comparaison des modèles sur la validation

Pour chaque horizon, tous les modèles sont ajustés sur le train. Le réglage de \(k\) (k-NN) et de la profondeur (arbre) se fait sur la validation, par la précision moyenne (AP). Le seuil de chaque modèle est choisi sur la validation, par la même règle pour tous. Le test n’est pas utilisé ici.

CRITERION = "f1"      # "f1" : F1 maximal ; "cout" : coût moyen minimal (c_FN / c_FP = 5, hypothèse provisoire)
R = {h: pipeline_horizon(raw, h, criterion=CRITERION) for h in HORIZONS}

for h in HORIZONS:
    sel = R[h]["selection"]
    print(f"horizon {h} min | k retenu : {sel['k']} | profondeur retenue : {sel['profondeur']} "
          f"| modèle retenu (AP validation) : {R[h]['chosen']}")
    print("seuils :", {k: round(v, 2) for k, v in R[h]["taus"].items()})
    display(R[h]["val_table"].round(3).T)
